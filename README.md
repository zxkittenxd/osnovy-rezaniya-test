# Основы резания и режущий инструмент — тест

Одностраничный интерактивный тест (104 вопроса) по теме «Основы резания и режущий инструмент».

- Режимы: по одному вопросу / все сразу
- Перемешивание вопросов и вариантов ответа
- Подсказки с ключами, статистика и оценки
- Работает полностью в браузере, без сборки и зависимостей

## Демо

Сайт опубликован на GitHub Pages: <https://zxkittenxd.github.io/osnovy-rezaniya-test/>

## Как обновить

1. Отредактируйте `index.html`.
2. `git add -A && git commit -m "update" && git push`.

Через 1–2 минуты изменения появятся на GitHub Pages.
